# Super Trunfo - Desafio Final (Estruturas de Decisão em C)

## 💡 Descrição
Programa em C que compara duas cartas de países com base em **dois atributos numéricos** escolhidos pelo jogador.  
Usa **menus dinâmicos (switch)**, **estruturas de decisão aninhadas** e o **operador ternário** para determinar o vencedor.

---

## 🧱 Atributos das Cartas
- População  
- Área  
- PIB  
- Pontos Turísticos  
- Densidade Demográfica (População / Área)

---

## 🚀 Como Compilar
```bash
gcc super_trunfo_final.c -o super_trunfo_final

./super_trunfo_final
